# 联系人勾选管理页面

页面只管理本地离线助手配置，不读取微信通讯录、不启动真实自动回复、不发送微信消息。联系人来自用户手动录入和现有白名单配置；显示名称不是官方微信用户 ID。

## 首次安装

打开终端，进入运行项目目录：

```bash
cd /Users/leecy/Desktop/wecom-ai-assistant/微信自动化回复
python3.11 -m venv .venv
.venv/bin/python -m pip install -e '.[dev,assistant]'
cp -n assistant.user.example.json assistant.local.json
mkdir -p logs inbox
```

需要 Python 3.11 或更高版本。已有 `.venv` 时可直接使用，无需重新创建；`cp -n` 保留已有个人配置。首次模板白名单为空，页面不会自动允许任何联系人。

## 日常启动

方式一：在 Finder 中双击项目目录里的 `启动联系人管理.command`，保持启动终端运行。

方式二：在终端执行：

```bash
cd /Users/leecy/Desktop/wecom-ai-assistant/微信自动化回复
.venv/bin/python -m src.core.assistant.web \
  --config assistant.local.json --db logs/assistant.sqlite3 --port 8765
```

看到 `Uvicorn running on http://127.0.0.1:8765` 后，在浏览器访问 `http://127.0.0.1:8765`。页面不会自行打开微信或启动自动回复。首次安装与终端双击启动的权限链不等同于页面服务验收；本轮直接 Python 启动和 HTTP 退出已通过隔离进程实测。

## 页面内退出与再次启动

1. 如果需要保留当前勾选，先点击“保存选择”。
2. 点击页面右上角“退出程序”，在确认框中点击“确认退出”。有未保存选择时，会显示丢失提醒。
3. 页面显示“退出请求已提交”。服务完成正在处理的请求后正常退出；浏览器标签页可手动关闭。
4. 再次使用时重新运行启动脚本或启动命令，然后刷新页面；已保存的联系人、白名单、记忆和附件记录保留。

退出按钮只关闭当前本地管理服务，不退出微信客户端、不停止其他离线监听或其他 Python 进程。关闭浏览器标签页本身不会停止服务。也可在启动终端按 Control+C 停止。

只有通过本项目的 `python -m src.core.assistant.web` 或启动脚本启动时，按钮才可用。若用其他 ASGI 容器加载 `create_app` 且未提供受控退出回调，按钮禁用，需要在对应终端停止宿主服务。

服务退出后地址不可访问是正常现象；页面不会在服务断开后声称已核对整个系统的进程状态。若退出请求报错或连接中断，可在启动终端按 Control+C 核查退出。

## 常见启动问题

- `.venv/bin/python` 不存在：先执行首次安装步骤。
- `assistant.local.json` 不存在：执行上面的 `cp -n` 命令；双击启动脚本也会在缺失时复制模板，不覆盖已有配置。
- `Address already in use`：该端口已有服务。先退出原管理服务，或改用 `--port 8766` 并访问 `http://127.0.0.1:8766`；不要按名称结束全部 Python 进程。
- 页面仍显示旧按钮：刷新页面。服务代码更新后需要重启管理服务，不能只刷新静态页面。
- 记忆或附件页提示数据库占用：先停止使用同一数据库的离线 `watch`；退出管理页面不会代替你停止它。

## 勾选联系人

1. 点击“添加联系人”，填写显示名称以及本地消息事件中精确的 `conversation`、`sender`。
2. 新联系人默认未勾选，添加动作不授予回复权限。
3. 逐项勾选，或搜索后“选择当前筛选结果”。搜索和筛选不会清除隐藏的已选项。
4. 点击“保存选择”。未保存前不会更改配置；“重置”会丢弃当前草稿选择。
5. 刷新页面后回显已保存的勾选。取消勾选不会删除联系人资料，仍可再次选择。

可使用“全部、已选、未选”筛选，或取消全部选择后保存空白名单。联系人按会话和发送者组合区分，同名联系人不会合并。上限为 500 位。

保存使用文件锁、原子替换和版本比对。其他页面或 CLI 修改了配置时，本页拒绝覆盖，请撤销并刷新后重新选择。`contacts` 保存手动联系人目录，`whitelist` 保存已勾选的精确身份；其他配置字段保留。

白名单仅影响使用同一配置文件的离线助手。离线 `watch` 会重新加载变更；曾移除的会话重新勾选后仍需显式 `resume`，旧积压不补发。真实微信仍限定 Ri，勾选不代表其他联系人已经完成客户端适配。

## 记忆和附件

“查看”可进入已保存联系人的记忆页；也可通过左侧导航切换：

- 会话记忆：选择已保存的联系人，查看、添加或删除显式记忆，可设置长期、1 天、7 天或 30 天有效期。
- 附件资料：查看已有解析资料的名称、来源限制与 ID，并移除检索资料。原文件和历史消息保留。
- 本轮页面不提供文件上传；使用 `attachment-add` 命令导入 inbox 文件。操作方法见[手动管理说明](assistant-user-management.md)。

记忆和附件访问需要先停止占用同一数据库的离线监听。数据库被占用时页面显示提示，不绕过进程锁；联系人勾选仍可保存。页面本身不持有长期数据库连接。

## 本地服务约束

- 服务入口固定绑定 `127.0.0.1`，没有公开网络监听选项。
- 修改接口要求本服务的防跨站请求令牌，并核对浏览器 Origin；不开放跨域接口。
- 校验 Host，防止任意域名访问本地管理接口。
- 页面不用 CDN、远程字体或外部图片；本轮新增依赖为 0。
- API 不返回完整模型配置或密钥。页面和 API 响应不缓存，资源使用同源内容策略。
- 没有真实发送、启动微信监听、停止微信监听的 API。

## 实现与验证入口

| 文件 | 作用 |
| --- | --- |
| `src/core/assistant/contact_book.py` | 联系人目录、勾选保存和版本冲突校验，包含 Protocol |
| `src/core/assistant/web.py` | 独立 FastAPI 本地管理服务，包含 WebFactoryProtocol |
| `src/core/assistant/web_assets/` | 原生 HTML、CSS、JavaScript 页面 |
| `tests/test_assistant_contact_book.py` | 目录持久化、同名区分、无效选择与并发冲突 |
| `tests/test_assistant_web.py` | API、请求保护、数据库锁和记忆管理 |
| `scripts/check_contact_ui.cjs` | 独立临时配置及数据库的真实浏览器交互验收 |

浏览器验收需要本机 Chrome 和开发环境中的 Playwright。项目运行不依赖 Playwright。已经提供 Playwright 的环境可执行：

```bash
node scripts/check_contact_ui.cjs
```

若包不在默认模块路径，使用本机 Playwright 的实际目录设置 `NODE_PATH`；不需要为运行页面安装浏览器测试依赖。验收产物在被 Git 忽略的 `logs/contact-ui-check/`，联系人为隔离测试数据，不会写入个人配置。浏览器测试覆盖手动添加、默认不勾选、保存、刷新回显、搜索与筛选全选、撤销未保存选择、记忆增删、附件空状态及桌面/手机宽度检查；真实发送数为 0。
