使用说明

启动与退出

双击项目中的“启动联系人管理.command”，或在项目目录执行：

.venv/bin/python -m src.core.assistant.web

访问 http://127.0.0.1:8765。点击右上角“退出程序”关闭本地管理服务；再次使用时重新运行启动命令。

首次安装及配置步骤见项目 docs/contact-ui.md。关闭浏览器标签页不会退出服务。
